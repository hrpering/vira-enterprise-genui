# PR-036: Runtime Web Render Model

## Goal
Create a strict framework-neutral render-preparation boundary from source-plan-validated composition to exact semantic component bindings.

## Scope
- Add `prepareRenderModel` public boundary.
- Validate ComposedExperience against its source ExperiencePlan.
- Resolve every Capability through Component Adapter exact mappings.
- Preserve semantic region/capability order.
- Return immutable plan/mode/layout/disclosure/region/component-reference data.
- Fail closed for forged composition or missing component mapping.
- Add Runtime Web public/dependency surface, tests, and docs.

## Out of scope
- Component implementations.
- Props/data bindings.
- Brand token resolution.
- HTML/DOM/CSS.
- Browser event listeners.
- RuntimeAction construction/execution.
- Network/model/tool calls.

## Acceptance criteria
- Detached/forged composition cannot reach the RenderModel boundary.
- Every rendered semantic capability has an exact Component Adapter mapping.
- No fallback/default component exists.
- RenderModel does not duplicate ExperiencePlan task state/DomainData.
- No executable/browser implementation values enter the model.
- Output is immutable and serializable.

## RE/QC focus
Look for integrity-gate bypass, fallback components, component implementation leakage, props/state/data duplication, mutable references, order drift, DOM/browser behavior, or cross-package dependency violations.
