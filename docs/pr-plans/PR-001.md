# PR-001 — Repository foundation

## Goal

Create the minimum monorepo and CI foundation required to implement Vira Enterprise GenUI without introducing product behavior.

## Scope

- pnpm workspace.
- TypeScript strict baseline.
- ESLint baseline.
- Vitest command baseline.
- GitHub Actions verification workflow.
- Package placeholders matching the approved architecture.
- Architecture boundary documentation and accepted ADRs.
- Pull request and reverse-engineering review templates.

## Out of scope

- Protocol models.
- Runtime state logic.
- Planner/composer behavior.
- Rendering.
- React/Web Component implementation.
- Network or realtime infrastructure.
- Message queues.
- Customer/domain-specific integrations.

## Acceptance criteria

- `pnpm lint` is defined.
- `pnpm typecheck` is defined.
- `pnpm test` is defined.
- `pnpm build` is defined.
- `pnpm verify` runs all four checks.
- All approved top-level packages exist as independent workspace packages.
- Architectural package boundaries are documented.
- No package contains product logic.
- CI has read-only repository permission.

## RE/QC focus

Confirm this PR is foundation-only, creates no hidden runtime behavior, introduces no customer/domain assumptions, and does not collapse package boundaries before implementation starts.
