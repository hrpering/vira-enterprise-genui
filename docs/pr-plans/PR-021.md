# PR-021: Deterministic Planner Golden Suite

## Goal
Freeze the completed Planner phase behind multi-domain golden pipeline fixtures without adding new planner product behavior.

## Scope
- Add eight deterministic successful pipeline fixtures spanning resolve/interact/settled modes.
- Add fail-closed fixtures for unmapped blockers, unsupported Intent version, invalid plan ID, and unrequested candidate state.
- Execute each successful fixture through `planExperience` then `planComposition` twice and compare exact outputs.
- Assert canonical serialization, frozen outputs, and absence of presentation/execution fields.
- Document deterministic reference-planner invariants.

## Out of scope
- New planner runtime APIs or behavior.
- LLM/model/provider configuration.
- Domain/customer adapters.
- Composer regions/layout/disclosure.
- Components/runtime-web/DOM.
- Network/tool execution.

## Acceptance criteria
- Eight successful fixtures produce exact canonical plans and directives.
- Repeated runs with canonical round-tripped inputs are identical.
- Fail-closed cases preserve expected error code/path boundaries.
- Golden outputs remain presentation/execution neutral.
- No package source file changes are required by this PR.

## RE/QC focus
Look for fixtures that merely mirror implementation without covering architecture invariants, customer-specific assumptions, hidden nondeterminism, loose assertions that permit drift, presentation leakage, or test changes that redefine behavior instead of detecting regressions.
