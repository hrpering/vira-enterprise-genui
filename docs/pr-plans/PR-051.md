# PR-051: `<vira-experience>` Web Component Shell

## Goal
Add the standards-native Web Component host shell as a thin wrapper over the public Runtime Web SDK without reimplementing GenUI behavior.

## Scope
- Turn `packages/web-component` from placeholder into a real package depending only on `runtime-web`.
- Define canonical tag name `vira-experience`.
- Add `createViraExperienceElementClass(HTMLElementBase)` for browser/test platform injection.
- Add `defineViraExperienceElement(platform?)` with explicit duplicate/platform failures.
- Expose imperative `configure`, `mount`, `unmount`, `currentState`, lifecycle-status, and `dispose` methods.
- Keep structured/executable configuration as JavaScript input; do not serialize it into HTML attributes.
- Delegate configuration/mount/state ownership to `createViraGenUI`.
- Auto-unmount on `disconnectedCallback` while preserving configuration for reconnect/remount.
- Add tests and documentation.

## Out of scope
- dispatch/patch forwarding.
- CustomEvent emission.
- observed attributes / JSON-in-attribute configuration.
- Shadow DOM/CSS/component implementation.
- React wrapper.
- automatic remount on reconnect.

## Acceptance criteria
- `web-component` imports only Runtime Web public APIs.
- importing the package does not require browser globals.
- SDK configuration remains lazy and executes no DOM work during `configure`.
- mount delegates to Runtime Web SDK without duplicating validation/state.
- disconnect releases the active experience but does not permanently dispose the element.
- explicit dispose is idempotent and permanently blocks reconfiguration/mount.
- duplicate custom-element registration fails explicitly rather than silently replacing/accepting another definition.

## RE/QC focus
Look for runtime/planner/composer imports, browser-global access at module load, JSON attribute configuration, duplicated SDK state, hidden DOM rendering, auto effect execution, non-idempotent cleanup, leaked mounted state after disconnect, or silent custom-element registry collisions.
