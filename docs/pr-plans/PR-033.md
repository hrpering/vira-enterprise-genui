# PR-033: Action Adapter Contract

## Goal
Map enterprise-native event aliases into semantic action descriptors while keeping RuntimeAction identity/source/permission ownership in Runtime Web/Core.

## Scope
- Add versioned ActionAdapterContract.
- Add bounded exact event -> semantic action-type mappings.
- Reject duplicate event mappings.
- Add `adaptActionEvent` returning only `{ type, payload }`.
- Validate payload as canonical JsonObject.
- Fail closed for unmapped events.
- Reject action id/source/permission/callback/execution/network fields.
- Return frozen serializable outputs.

## Out of scope
- RuntimeAction construction.
- Action ID generation.
- Action source assignment.
- Permission evaluation/authorization.
- Side-effect execution.
- Network/tool calls.
- Retries/queues.

## Acceptance criteria
- Adapter cannot set or spoof RuntimeAction `id` or `source`.
- Exact event mapping only; no fuzzy/wildcard routing.
- Payload is canonical data only.
- Unmapped events fail closed.
- No permission or execution surface exists.
- Caller-owned payload is not retained mutably.

## RE/QC focus
Look for source/id spoofing, permission confusion, executable callbacks, hidden side effects, network/tool behavior, wildcard event routing, reflected caller data in errors, mutable payloads, or Runtime Core dependency inversion.
