# PR-084: Puck human style controls

## Goal
Give human Studio authors modern visual styling controls inside the existing Puck property panel without adding raw CSS, arbitrary fonts, arbitrary URLs, or a second editor/runtime model.

## Scope
- add `@vira-enterprise-genui/studio-design` as an optional higher-level catalog augmentation package;
- enable selected brand components with a reserved, serializable set of design props;
- support open safe-hex colors or brand-locked color palettes;
- support registered-font selection;
- support solid/linear-gradient backgrounds, typography, spacing, radius, shadow, alignment, width and basic row/column/grid layouts;
- give color props a Puck custom color picker;
- add min/max/step metadata to Puck number fields for design values;
- strip Vira design props before calling trusted brand renderers and apply them through a safe React wrapper in Studio preview;
- revalidate design values in the shared preview/publish gate;
- add contract coverage for open/palette modes, Puck metadata, React preview styling and deny paths.

## Security / ownership boundaries
- no raw CSS string field;
- no `style` object from the author;
- no HTML/JS/JSX/code field;
- colors are `#RRGGBB` only;
- fonts are exact values from the host-provided registered list;
- numeric design values use fixed bounded ranges;
- background images, URLs, remote fonts and arbitrary effects are not introduced;
- design props remain ordinary canonical Studio props, so Puck stays replaceable and StudioDocument schema is unchanged.

## Acceptance criteria
- a human can change visual design from the Puck right-hand property panel;
- open mode permits any safe hex color while palette mode restricts to brand colors;
- font selection is restricted to registered fonts;
- Puck number fields expose safe min/max/step controls;
- Studio React preview visibly applies validated style choices;
- brand renderer functions never receive reserved Vira design props;
- publish rejects invalid colors, oversized values and incomplete gradients;
- the PR is one commit on top of PR-083.
