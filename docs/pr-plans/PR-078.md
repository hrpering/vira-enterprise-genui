# PR-078: Studio data binding catalog and commands

## Goal
Add safe no-code data binding through an exact enterprise-declared source catalog without introducing expressions or arbitrary paths.

## Scope
- add `@vira-enterprise-genui/studio-binding`;
- define versioned state/domain source catalog;
- declare exact semantic paths and primitive value types;
- validate every existing StudioDocument binding against registered sources and compatible component props;
- expose compatible property-panel binding targets;
- add transactional `setStudioBinding` and `clearStudioBinding` commands;
- remove competing static prop values when a binding is set;
- fail closed when clearing a required binding would leave an invalid component;
- add Pegasus-style contract coverage.

## Out of scope
- JSONPath or expression languages;
- arbitrary transforms/eval;
- API/network configuration;
- runtime data fetching;
- authorization or secret resolution;
- Puck-specific source state.

## Acceptance criteria
- unregistered sources fail closed;
- source/prop type mismatch fails closed;
- non-bindable props cannot be bound;
- source selection is exact and deterministic;
- mutation is transactional and returns a fully revalidated StudioDocument;
- static+binding conflicts cannot be introduced;
- no existing core/runtime package behavior changes.
