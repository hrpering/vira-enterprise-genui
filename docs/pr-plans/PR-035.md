# PR-035: Adapter SDK Golden Suite

## Goal
Close the Adapter SDK phase with deterministic multi-domain integration fixtures covering all eight adapter surfaces without changing package product behavior.

## Scope
- Add travel and support golden integration fixtures.
- Exercise Brand, Intent, Recipe, Domain, Data, Component, Action, and Policy adapters together.
- Assert exact canonical outputs and deterministic round-trips.
- Assert frozen outputs.
- Add fail-closed checks for unmapped intent, wrong domain, missing projected data, unmapped component/event/recipe policy.
- Document the phase boundary.

## Out of scope
- New Adapter SDK APIs.
- RuntimeAction construction/permissions.
- Planner/Composer execution.
- DOM/framework rendering.
- Network/tool/model calls.

## Acceptance criteria
- Every Adapter SDK surface is exercised by the reference integration path.
- Golden outputs are deterministic and serializable.
- Failure boundaries remain fail closed.
- No source/package implementation file changes are required by this PR.
- Integration fixtures contain no executable/secret/transport values.

## RE/QC focus
Look for loose assertions, fixtures that smuggle implementation/network/auth behavior, hidden nondeterminism, customer-specific coupling, or tests that redefine package behavior instead of locking it.
