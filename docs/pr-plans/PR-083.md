# PR-083: Studio enterprise golden gate

## Goal
Close the Experience Studio implementation plan with one cross-package Pegasus-style golden integration and explicit deny paths, without adding production behavior.

## Scope
- add one nested flight-search Studio fixture;
- generate/validate it through the provider-neutral AI draft boundary;
- round-trip the nested search view through the Puck authoring seam;
- replace a static results prop with an approved domain binding;
- bind an approved search action and success/empty/error routes;
- publish through the shared preview/publish gate;
- run the published interaction through the Studio runtime bridge and existing Runtime Web permission path;
- resolve the results binding after a correlated success outcome;
- add deny assertions for unregistered component/source/action, forged publication, and stale completion;
- document the Studio closure gate and remaining CI requirement.

## Explicitly out of scope
- new production APIs or behavior;
- merge/release automation;
- provider/model/network implementation;
- arbitrary HTML/CSS/JavaScript;
- general workflow orchestration;
- weakening any existing security/permission gate.

## Acceptance criteria
- the happy path crosses AI draft, Puck, binding, flow, publish, Studio runtime, and Runtime Web public surfaces;
- nested Puck structure returns to the same editor-neutral Studio hierarchy;
- authoring deny paths fail before publication;
- forged/stale runtime data fails before view transition;
- no production package file changes;
- this PR is exactly one commit on top of PR-082.
