# PR-043: Runtime Web Mount Environment Integration

## Goal
Make semantic accessibility and container-responsive policy mandatory inputs to transactional DOM mounting so neither contract remains detached metadata.

## Scope
- Require mount input: composition, source plan, component adapter, accessibility policy, responsive policy.
- Reuse `prepareAccessibleRenderModel` for render integrity + accessibility validation.
- Validate ResponsivePolicy before touching the DOM Port.
- Extend trusted DOM Port with container inline-size measurement.
- Resolve one semantic responsive band before `begin()`.
- Pass validated accessibility policy + resolved band in the mandatory DOM begin context.
- Preserve existing ordered mount, atomic commit, rollback, exception containment, and idempotent disposal guarantees.

## Out of scope
- concrete browser DOM implementation.
- ResizeObserver/update subscriptions.
- actual focus/ARIA/live-region mutations.
- CSS/media-query generation.
- component props/data binding.
- effect execution/network/tool calls.

## Acceptance criteria
- Invalid render/accessibility/responsive input causes zero DOM Port calls.
- Container measurement occurs only after all declarative inputs validate.
- Invalid/thrown container measurement prevents `begin()` and component mounting.
- `begin()` receives semantic accessibility policy and resolved container band.
- Transaction rollback/disposal behavior remains unchanged after environment integration.
- Raw host exception messages never cross the boundary.

## RE/QC focus
Look for accessibility/responsive bypass, viewport fallback, DOM calls before validation, measurement exception reflection, partial mount leaks, responsive re-selection inside components, or regression in rollback/disposal ordering.
