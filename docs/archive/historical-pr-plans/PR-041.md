# PR-041: Runtime Web Accessibility Contract

## Goal
Add an explicit semantic accessibility policy boundary on top of a source-validated RenderModel without hard-coding DOM/ARIA implementation details.

## Scope
- Add versioned AccessibilityPolicy.
- Require explicit focus-on-mount, focus-on-update, status-announcement, and error-announcement choices.
- Prevent disabling error announcements entirely.
- Add `prepareAccessibleRenderModel` that first passes the existing RenderModel integrity/component-mapping gate.
- Return one immutable wrapper containing the validated RenderModel + semantic accessibility policy.
- Reject DOM selectors, ARIA attributes, tabindex, CSS, label text, callbacks, and framework fields.

## Out of scope
- actual focus movement.
- `aria-*` mutation.
- live-region DOM creation.
- accessible-name text generation.
- keyboard event handlers.
- component implementation.
- network/model/tool calls.

## Acceptance criteria
- Accessibility behavior is explicit; there are no hidden defaults.
- Error announcements cannot be turned fully off.
- Forged/detached compositions cannot reach the accessibility wrapper.
- Policy contains semantics, not DOM implementation data.
- Caller-owned values are normalized/frozen.

## RE/QC focus
Look for hidden defaults, DOM/ARIA/CSS leakage, inaccessible error suppression, raw labels/text injection, component implementation ownership, integrity-gate bypass, or mutable output.
