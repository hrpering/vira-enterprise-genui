# PR-042: Runtime Web Container Responsive Policy

## Goal
Make Runtime Web responsive to its embedding container through an explicit deterministic band policy rather than viewport/device assumptions.

## Scope
- Add versioned ResponsivePolicy with `strategy: "container"` only.
- Define bounded semantic container bands with strictly increasing `minInlineSizePx` thresholds.
- Require the first band to start at zero.
- Add deterministic `resolveResponsiveBand(policy, inlineSizePx)`.
- Reject viewport/media-query/device/CSS/component fields.
- Return frozen serializable policy/band outputs.

## Out of scope
- reading `window.innerWidth`.
- ResizeObserver wiring.
- CSS/media-query generation.
- component layout props.
- DOM mutation.
- device detection/user-agent logic.

## Acceptance criteria
- Container size is the only responsive input.
- Band IDs are semantic and unique.
- Thresholds are explicit, bounded, and strictly increasing.
- No hidden default bands or viewport fallback exists.
- Resolver is deterministic for fractional container sizes.

## RE/QC focus
Look for viewport/device coupling, hidden defaults, unsorted/overlapping thresholds, CSS/media-query leakage, mutable bands, semantic-ID duplication, or non-deterministic selection.
