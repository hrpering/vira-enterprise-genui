# PR-065: CSP Host Requirements Contract

## Goal
Expose a framework-agnostic, immutable set of minimum Content Security Policy requirements for hosting Vira Enterprise GenUI without making the Security package own the enterprise application's CSP header or server middleware.

## Scope
- Add a versioned `CspHostRequirements` contract.
- Derive required `connect-src` origins from the validated Security `NetworkPolicy`.
- Require script policy to exclude `'unsafe-inline'` and `'unsafe-eval'`.
- Require inline script attributes to be denied.
- Require object sources to be denied.
- Sort normalized required connect origins for deterministic output.
- Keep output deeply immutable and detached from caller-owned input.
- Surface invalid NetworkPolicy errors under `$.networkPolicy...`.
- Add contract tests and documentation.

## Explicitly out of scope
- setting HTTP response headers.
- creating or mutating `<meta http-equiv>` elements.
- parsing an existing host CSP string.
- merging or serializing a complete host CSP.
- Express/Helmet/Next.js/framework middleware.
- nonce/hash generation or lifecycle.
- report-only policy/report endpoint configuration.
- claiming Vira's required connect origins are the host's complete allowlist.
- replacing NetworkPolicy method-level enforcement with CSP.

## Acceptance criteria
- valid NetworkPolicy produces deterministic normalized CSP requirements.
- empty NetworkPolicy produces no Vira-required connect origins.
- HTTP methods do not alter `connect-src` requirements for the same origin.
- wildcard/malformed network origins fail through the NetworkPolicy owner.
- no raw caller policy reference is retained.
- all returned requirement structures are frozen.
- Security gains no framework/server dependency.
- no code in the contract performs DOM or network I/O.

## RE/QC focus
Look for host CSP ownership drift, header/meta side effects, CSP string parsing, method-level claims inside `connect-src`, unsafe inline/eval exceptions, mutable output, duplicated NetworkPolicy parsing, wildcard acceptance, framework coupling, or accidental replacement of runtime NetworkPolicy enforcement.
