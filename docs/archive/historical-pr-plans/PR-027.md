# PR-027: Adapter SDK Brand Profile

## Goal
Establish a strict framework-neutral brand identity contract based on semantic token references rather than raw styling implementation.

## Scope
- Add versioned BrandProfile contract.
- Validate semantic brand IDs and bounded display names.
- Define a frozen canonical set of brand token roles.
- Accept only semantic token references for those roles.
- Reject CSS values, URLs, executable/style bags, unknown fields/roles, and accessor-backed input.
- Return recursively frozen serializable data.
- Expose Adapter SDK package public/dependency surface.

## Out of scope
- CSS/theme generation.
- DOM/style injection.
- Remote logos/fonts/assets.
- Component selection or rendering.
- Runtime state/actions.
- Customer/domain data.

## Acceptance criteria
- No raw CSS or URL is accepted as a token reference.
- Unknown token roles fail closed.
- Protocol remains owner of semantic identifier grammar.
- Caller-owned input is not retained mutably.
- Output is immutable and serializable.
- Adapter SDK does not acquire runtime/composer ownership.

## RE/QC focus
Look for arbitrary style bags, raw CSS/URL injection, mutable token-role truth, duplicate semantic-ID grammar, accessor execution, component/runtime leakage, or customer-specific branding logic.
