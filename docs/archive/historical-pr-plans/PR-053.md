# PR-053: Web Component Golden Integration Gate

## Goal
Close the standards-native Web Component phase with one deterministic integration gate over registration, Runtime Web delegation, canonical DOM events, lifecycle cleanup, and remount behavior without adding production behavior.

## Scope
- Add a deterministic registered `<vira-experience>` integration fixture.
- Exercise injected platform registration with explicit CustomEvent factory.
- Exercise configure -> mount -> user dispatch -> host patch -> invalid event.
- Assert canonical native event order and unchanged Runtime Web payload ownership.
- Exercise disconnect unmount, remount with retained configuration, and permanent dispose.
- Assert DOM/effect work remains delegated to Runtime Web/host ports.
- Add tests and documentation only.

## Out of scope
- new Web Component production APIs.
- Shadow DOM/CSS/component implementation.
- automatic effect execution.
- JSON attributes.
- React wrapper.
- network/tool/model calls.

## Acceptance criteria
- PR changes tests/docs only.
- registration path preserves injected event factory.
- configure performs no mount/DOM work.
- user dispatch emits user action + data-only host effect without state revision change.
- host patch emits host action + authoritative statechange and advances revision exactly once.
- invalid event emits canonical error and consumes no extra action ID.
- disconnect releases mounted resources and allows remount with the same normalized configuration.
- dispose is permanent/idempotent.

## RE/QC focus
Look for hidden production changes, duplicated runtime state, effect execution, payload rewriting, source spoofing, broken cleanup ordering, registration factory loss, state persistence across explicit remount when a fresh RuntimeState is expected, or tests that bypass the public element surface.
