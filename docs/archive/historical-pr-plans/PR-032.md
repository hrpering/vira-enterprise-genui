# PR-032: Data Adapter Contract

## Goal
Project canonical DomainData into deterministic semantic top-level fields without raw-response parsing, nested selectors, or executable transforms.

## Scope
- Add versioned DataAdapterContract.
- Bind one exact DomainData domain/type.
- Validate bounded one-to-one top-level semantic field mappings.
- Add `projectDomainData` using Protocol DomainData normalization.
- Require every declared source field to exist.
- Return a frozen canonical JsonObject projection.

## Out of scope
- Raw API/tool response parsing.
- JSONPath/nested traversal.
- Transform expressions/callbacks.
- Business inference/defaulting.
- Runtime state mutation.
- Component rendering.
- Network/tool execution.

## Acceptance criteria
- Protocol remains owner of DomainData validation.
- Wrong domain/type or non-object data fails closed.
- Missing source fields fail closed.
- Duplicate source or target bindings fail closed.
- No nested path/expression/executable transform surface exists.
- Caller-owned data is not retained mutably.

## RE/QC focus
Look for raw-response interpretation, nested selector creep, transform execution, silent missing-field defaults, duplicate target overwrites, domain/type fail-open behavior, mutable output, or runtime/component ownership leakage.
