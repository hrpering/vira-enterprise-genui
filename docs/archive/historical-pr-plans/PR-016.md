# PR-016: Pure runtime reducer

## Goal
Compose strict state/action/policy normalization, permissions, patch/lifecycle primitives, canonical errors, and data-only effects into one deterministic public runtime boundary.

## Scope
- Add pure `reduceRuntime(stateInput, actionInput, policyInput)`.
- Add strict `parseRuntimeState` and reuse shared experience-id validation.
- Normalize all three public inputs before effects/transitions.
- Invalid policy fails closed.
- Permission deny occurs before preflight/effects/mutation.
- After deny filtering, preflight built-in/lifecycle validity before confirm/allow handling.
- Confirm returns normalized unchanged state plus data-only effect only for preflight-valid actions.
- Allowed built-in patch/lifecycle actions call their owning primitives.
- Other allowed actions return frozen host-action effects without execution.
- Terminal states block patch mutation and generic host effects.

## Out of scope
- Executing host effects.
- Confirmation token/UX implementation.
- Async/network/tool calls.
- DOM/framework behavior.
- Planner/composer/adapter integration.
- Retry queues or telemetry.

## Acceptance criteria
- Invalid/forged state, action, or policy cannot produce effects.
- Default-denied actions produce no effects/state changes.
- Confirm never executes or mutates and is not emitted for malformed/illegal built-ins.
- Built-in patch/lifecycle actions require explicit allow and use owning primitives.
- Generic host effects are data only and blocked after terminal lifecycle.
- System/host source grants no bypass.
- Reducer/effects/errors/states returned at this boundary are normalized, deterministic, serializable, and frozen.

## RE/QC focus
Look for forged-state/policy bypass, permission-after-mutation ordering, confirm-as-allow, confirmation of malformed actions, source privilege, network/backend execution, terminal-state effects, duplicated patch/lifecycle mutation logic, mutable outputs, or raw low-level errors.
